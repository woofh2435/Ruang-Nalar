Tahap p2: cara memasang
1. Salin SEMUA isi zip ini ke folder proyek Ruang Nalar-mu (folder yang berisi README.md dan folder src), timpa kalau diminta.
   Berkas yang tidak ada di zip tidak disentuh, jadi proyek, ebook, dan konfigurasi lain tetap utuh.
2. Folder docs/ adalah hasil build baru. Berkas lama di docs/assets/ dengan nama berbeda boleh dihapus (tidak wajib).
3. index.html di akar adalah build satu-berkas yang langsung tayang di GitHub Pages. Pintu masuk Vite asli tersimpan sebagai index.sumber.html (hanya ikut bila berubah).
4. Kalau zip memuat berkas di supabase/patch/, jalankan isinya SEKALI di Supabase -> SQL Editor (aman diulang).
5. Jangan lupa Commit di GitHub, lalu tunggu 1-2 menit sampai Pages memperbarui.
